# 공통 브리프 (모든 에이전트 공통 컨텍스트 — 변경 금지, 캐싱 대상)

## 제품
위치 기반 "음식점 전용" 추천 모바일 앱 (가칭: 찐맛 / JJINMAT).
- 지도앱(길찾기 중심)과 달리 음식점이 메인. 사용자가 조건 선택 → 소수(3~5곳) 큐레이션.
- 조건: 가격대, 음식 장르, 분위기, 음주 가능 여부, 거리.
- 별점 체계: 의도적으로 엄격(디플레이션). 평균 ≈ 2.5/5 목표, 분별력 극대화.
- 콜드스타트: 자체 리뷰 축적 전엔 외부 데이터 기반 사전 점수(prior).
  - 가중치↑: 고위 공직자 업무추진비 공개 내역에 자주 등장하는 음식점.
  - 가중치↓: 네이버지도 기준 광고/체험단/이벤트 리뷰 비율이 높은 음식점.
- 자체 리뷰 누적 시 prior → 사용자 데이터로 점진 전환(베이지안 수축).

## 제약
- 로컬 개발 경로: C:\Restaurant_Recommendation (Windows). 원격 저장소 경로와 동일 구조.
- 모바일 앱 (iOS/Android).
