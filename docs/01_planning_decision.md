# 기획팀 결정문 (찬성 vs 반대 토론 중재 결과)

| 쟁점 | 찬성 | 반대 | **결정** |
|---|---|---|---|
| 데이터 수집 | 외부 데이터로 prior | 네이버 크롤링은 약관·법적 리스크 high | **크롤링 금지.** 공식 API(카카오 로컬/네이버 검색 지역 API) + 공공데이터 + 제휴/수기 CSV만. 수집기는 교체 가능한 어댑터 구조 |

| 소수 큐레이션 | 선택 과부하 해소 | 독점 노출·조작 의혹 | ~~기본 3곳(최대 5).~~ **2026-11-02 사용자 결정 → 조건에 맞는 가게를 표시 별점 내림차순으로 끝까지 이어 보기**(아래 '추천 목록 이어 보기'). 각 추천에 이유(reason) 3줄 표시. 동점대(±0.1)는 일 단위 로테이션. 결과 부족 시 완화 순서: 분위기→가격→세부 메뉴→거리→장르 (음주는 완화 안 함. 2026-10-29 개정: 세부 메뉴 추가, 가격대·분위기 데이터가 아직 없어 이 둘을 먼저 완화 — 고른 메뉴를 지키는 쪽 우선) |

## MVP 범위
- 지역: 서울 중구(시청 인근, 업무추진비 공개 데이터 밀집) 1곳.
- 필터 5종, 엄격 별점 엔진, prior 엔진, 추천 3곳 + 이유, 자체 리뷰 작성.
- 제외(2차): ~~로그인 소셜연동~~(2026-10-30 채택 → '로그인·리뷰 신뢰·배포' 절), 리워드, 업주 콘솔(이의제기는 이메일 링크로 대체).

## 기술 스택
- 모바일: Expo(React Native) + TypeScript — Windows에서 개발 가능, iOS/Android 동시.
- 백엔드: Python FastAPI + SQLite(MVP) → PostgreSQL/PostGIS(확장 시).
- 점수 엔진: 순수 Python 모듈(`backend/app/scoring/`), 단위 테스트 필수.

## 점수 모델 v2 (2026-10 개정 — 사용자 승인, `docs/04_data_plan.md` 3-2)
개정 사유: 외부 평점(네이버 등)은 공식 API로 제공되지 않고 크롤링은 금지 → prior를 **합법적으로 확보 가능한 공공 신호** 위주로 재구성.
```
prior_raw = 0.30 * 업력      min(log1p(영업연수)/log1p(20), 1)        # 인허가일자 opened_at, 없으면 0
          + 0.25 * 업무추진비  min(log1p(방문수)/log1p(300), 1), 1회 이하 0   # v2.2 (v2.1: 상한 30, 1회도 가점)
          + 0.15 * 위생등급    매우우수 1 / 우수 0.7 / 좋음 0.4 / 없음 0
          + 0.10 * 지정업소    모범음식점·안심식당·원산지표시 우수 중 1개 이상이면 1   # v2.1: 위생·서비스 지정만
          + 0.20 * 외부 평판   max(가이드 선정 점수, 제휴 평점 0~1), 둘 다 없으면 0.4(중립)   # v2.1
          - 행정처분           최근 3년(정확히 3년 전 당일 포함) 건당 0.05, 상한 0.15
                               # 건수 = 가게별 서로 다른 처분일자 수(같은 날 처분은 1건, 출처별 표기 차이로 중복 집계 방지)
          - 광고 감점          0.30 * clamp((ad_ratio-0.15)/0.5, 0, 1) * ad_conf
                               ad_ratio = 자체 리뷰 중 체험단·협찬·제공받아·원고료·소정의 표시 비율
                               ("협찬 아님", "원고료 받지 않았", "광고·협찬 없이" 등 부정 표현은 제외)
                               ad_conf  = min(리뷰수/10, 1)  (제휴 통계가 있으면 신뢰도 높은 쪽 사용)
                               하한: 광고 감점 ≤ 가점 합계의 50%
prior_star = strict_map(prior_raw)    # 시군구 단위 분위수 → 평균 2.5, 5.0 = 상위 ~0.1% (v2.3, 이전 4.5 이상 = 상위 ~3%)
final_star = (k*prior_star + n*user_mean) / (k + n)   # k=20 (변경 없음, 가중 리뷰 v2는 별도 승인)
근거 수준(evidence) = 데이터가 존재하는 신호 수(가점은 값이 있으면, 감점은 0보다 클 때만; 외부 평판은 가이드·제휴 값이 있을 때만, 중립 0.4 제외)
                   0 → "low"(근거 부족 표시, 단 자체 리뷰가 있으면 문구 생략), 1~2 → "mid", 3+ → "high"
```
### v2.1 (2026-10, 메인 판단으로 채택 — 사용자 위임)
- **외부 평판 가이드 점수**(restaurant_signals.kind): 미슐랭 별 `michelin_star` 1.0 · 빕 구르망 `michelin_bib` 0.85 · 서울미식 100선 `taste_of_seoul` 0.85 · 미슐랭 셀렉티드 `michelin_selected` 0.7 · 서울미래유산 `seoul_future_heritage` 0.7 · 지자체 향토음식점 `local_food` 0.7 · 경기도 으뜸맛집 `gyeonggi_best` 0.7. 여러 개면 최댓값. 미슐랭은 구조만 두고 **실데이터는 법무 확인 후 적재**.
- **백년가게**(`century_store`)는 외부 평판이 아니라 **업력 보정**: 업력 30년 이상으로 간주(opened_at 결측·짧을 때만) → 업력과 이중 가점 없음.
- **착한가격업소**(`good_price`)는 **점수 반영 안 함** → 분위기 태그 '가성비' 부여 + 대표메뉴·가격 출처(D4).
- 지정업소에 `origin_label_excellent`(원산지표시 우수) 추가.
- 공공 선정 목록 적재: 범용 지정 CSV 어댑터(상호·주소·좌표·kind·기준일·출처) + 가게 매칭(상호 정규화 + 도로명 주소 일치 또는 50m 이내). 매칭 실패 행은 수기 검토용 파일로 출력. 추천 이유에 "서울미식 100선(2025)"처럼 출처·연도 표시.
- **보류:** 블루리본·식신(제휴).
- **불가(2026-10-29):** 블로그 검색 API 광고 비율 — 네이버 검색 API 약관이 결과·파생물 저장과 AI 입력을 금지(`docs/04` 2-1 "쓸 수 없는 것").
- **제외:** 블로그 글 수 화제도 가점(체험단 마케팅에 유리 → 원칙 충돌), TV 출연 가점(협찬 방송·동명 업소).

### v2.2 (2026-10-29, 사용자 결정)
- **업무추진비 상한 30 → 300회**: 전국 수집(`expense_collector`) 결과 30회 이상 가게가 622곳이라 상위권이 모두 만점 → 변별력 확보.
- **1회 방문은 0점**: 한 번 기록은 재방문 근거가 아님(전국 데이터에서 1회 가게가 절반 이상). 근거 수준(evidence) 신호로도 세지 않음(기여 0). 추천 이유의 "공공기관 업무추진비 기록 N회" 배지는 사실 표기라 그대로.
- 결과: 2회 0.19 · 10회 0.42 · 30회 0.60 · 100회 0.81 · 300회+ 1.0 (×0.25). 반영은 `rebuild_scores` 재실행 후.

### v2.3 (2026-11-02, 사용자 결정 — 별점 엄격도)
- **5.0 = 시군구 상위 약 0.1%** (기존: 4.5 이상 = 상위 약 3%). `strict.SIGMA` = 2.5 / Φ⁻¹(0.999) ≈ 0.809, 평균 2.5 유지.
- 이유: 서울에서 5.0 표시 1,547곳(1.35%) — 추천 목록이 모두 5.0으로 보여 변별력 없음. 공공 신호가 상위권에서 포화돼 동점이 많은 것도 원인.
- 시뮬레이션(서울 114,432곳): 5.0 표시 1,547 → **72**, 4.5 이상 2,786 → 929, 4.0 이상 4,066 → 2,876. 대안 5.0 = 상위 0.01%(12곳)·공공데이터만 최대 4.5(4.5 가 2,786곳)는 기각.

v1(외부 평점 base 기반)은 폐기. 업무추진비 배지 문구·크롤링 금지 원칙은 그대로(공공기관 업무추진비 게시판 예외는 아래 업무추진비 절).
