# 디자인 시스템 v1 (미니멀) — 초안

> 상태: **초안, 사용자 승인 대기** (2026-11-05). 승인 전에는 코드(`mobile/src/theme/tokens.ts`)를 바꾸지 않는다.
> 승인되면 이 문서를 기준으로 토큰을 바꾸고 `screens.md` 의 색·토큰 언급을 맞춘다.

## 0. 현황 점검 (현재 `tokens.ts` 기준)

| 항목 | 현재 | 판단 |
|---|---|---|
| 하드코딩 값 | 색 1곳(`recommendations.tsx:485` `#FFFFFF`), 글자 크기 2곳(StarHero 56, ActionRail 아이콘 28) | 토큰화 상태 양호 |
| 색 | 22개(파랑 `accent`, 초록 `success`, 주황 `warning`, 배지 전용 4개, 칩 전용 4개) | 미니멀 기준으로는 많음. 강조색이 셋(주황·파랑·초록) 공존 |
| 글자 | 8단계, 굵기 4종(400/500/600/700), 최소 11px | 단계·굵기가 많고 11px 은 작음 |
| 간격 | 2~48, 9단계 | 대체로 4의 배수, 2px 은 불필요 |
| 모서리 | 0/4/8/12/16/pill | 단계 과다 |
| 그림자 | sm/md/lg 정의, **사용 0곳** | 삭제 가능 |
| **접근성 결함** | primary 버튼(흰 글자 on `#E4572E`) 대비 **3.68:1** → 15px 본문 기준 AA(4.5) 미달 | 반드시 수정 |

## 1. 원칙

1. **숫자가 주인공.** 화면에서 가장 크고 진한 것은 별점 하나. 나머지는 그 숫자를 받쳐 준다.
2. **색은 하나만.** 강조색(primary)은 ①주 행동 버튼 ②'최상' 별점 ③선택 상태에만 쓴다. 그 밖은 회색 단계로 처리.
3. **선보다 여백, 그림자 대신 면.** 구분은 여백 → 면 색(surface) → 1px 선 순서로 쓰고, 그림자는 쓰지 않는다.
4. **적은 단계.** 글자 5단계, 굵기 2종, 모서리 3종. 새 값이 필요하면 이 문서부터 고친다.
5. **색만으로 뜻을 전하지 않는다.** 별점 구간·상태·배지는 항상 텍스트를 같이 쓴다(기존 원칙 유지).

## 2. 색

중립 회색 + 강조색 1개 + 오류색 1개. 이름은 용도로 짓는다.

| 토큰 | Light | Dark | 용도 |
|---|---|---|---|
| `bg` | `#FFFFFF` | `#0E0F11` | 화면 배경 |
| `surface` | `#F4F4F5` | `#1A1B1E` | 카드·칩·입력창·시트 면 |
| `line` | `#E6E6E8` | `#2A2B2F` | 1px 구분선(장식용, 대비 요건 없음) |
| `text` | `#111214` | `#F2F2F3` | 본문·제목 (대비 18.7 / 17.1) |
| `textMuted` | `#5E6066` | `#A3A5AB` | 보조 문구 (흰 배경 6.3, surface 5.7 / 어두운 배경 7.8) |
| `textFaint` | `#8A8C92` | `#6B6D73` | 비활성·자리표시 문구 전용 (본문 금지, 대비 3.4 / 3.7) |
| `primary` | `#D1451F` | `#FF7A50` | 강조 1색 |
| `onPrimary` | `#FFFFFF` | `#0E0F11` | primary 위 글자 (대비 4.58 / 7.44, AA 통과) |
| `danger` | `#D0392B` | `#F0685C` | 오류·감점(부정 값)만 |
| `overlay` | `rgba(0,0,0,0.45)` | `rgba(0,0,0,0.6)` | 시트 뒤 어둡게 |

**없애는 색과 대체**

| 현재 | 대체 |
|---|---|
| `accent`(파랑) — 링크·"현장 작성"·사전 점수 막대 | 링크 = `text` + 밑줄, "현장 작성" = 태그 스타일, 막대 = `text` |
| `success`(초록) — '좋음' 구간·리뷰 평균 막대 | '좋음' = `text`(아래 3절), 막대 = `primary` |
| `warning`(주황) — "근거 부족" 문구 | `textMuted` + 앞에 아이콘/문구로 표시 |
| `govBadge*`, `adPenalty*`, `chip*` 8개 | 공용 **태그**(`surface` + `textMuted`)와 **선택**(`text` 면 + `bg` 글자) 두 가지로 통합. 광고 감점 안내는 `surface` 면 + `danger` 글자 |

## 3. 별점 표시 (starScale)

엄격 별점(평균 ≈ 2.5)이라 대부분 가게가 '평범'이다. 강조색은 진짜 드문 곳에만 쓴다.

| 구간 | 기준 | 숫자 색 | 라벨 |
|---|---|---|---|
| 평범 | 0 ~ 3.5 미만 | `textMuted` | "평범" |
| 좋음 | 3.5 이상 | `text` | "좋음" |
| 최상 | 4.5 이상 (상위 ~0.7%) | `primary` | "최상" |

- 숫자는 `hero` 크기, 고정폭 숫자(`fontVariant: ['tabular-nums']`)로 덱을 넘길 때 흔들리지 않게 한다.
- 구간 기준값은 바꾸지 않는다(기획 결정 사항). 바뀌는 것은 색뿐.

## 4. 글자

시스템 글꼴(iOS SF Pro / Android Pretendard 또는 기본 Roboto — §8 질문 1). 굵기는 **400(보통)·600(강조)** 두 가지만, `hero` 만 700.

| 토큰 | 크기 / 줄높이 | 굵기 | 용도 |
|---|---|---|---|
| `hero` | 56 / 64 | 700 | 별점 숫자 (StarHero 하드코딩 → 토큰화) |
| `title` | 22 / 30 | 600 | 화면 제목·가게 이름 |
| `heading` | 17 / 24 | 600 | 섹션 제목 |
| `body` | 15 / 22 | 400 (강조 600) | 본문·버튼 |
| `caption` | 13 / 18 | 400 (강조 600) | 보조 정보·태그·탭 라벨 |

- `display`(28) 는 `title` 로, `micro`(11) 는 `caption` 으로 흡수. 최소 글자 13px.
- 강조는 크기보다 **굵기 600 하나**로 한다. 색으로 강조하지 않는다.

## 5. 간격·모서리·선

**간격 (4 단위)**: `xs 4` · `sm 8` · `md 12` · `lg 16` · `xl 24` · `xxl 32` · `xxxl 48`
- `xxs 2` 삭제.
- 화면 좌우 여백은 `gutter = 20` 하나로 고정(릴스 카드 스펙 값을 토큰으로).
- 요소 사이 기본 간격 = `sm 8`, 묶음 사이 = `xl 24`, 섹션 사이 = `xxl 32`.

**모서리**: `sm 8`(버튼·입력창) · `lg 16`(카드·시트 위쪽) · `pill`(태그·칩). 4·12 삭제.

**선**: 두께 `hairline`(StyleSheet.hairlineWidth) 하나, 색 `line`. 목록 구분은 선보다 여백을 먼저 쓴다.

**그림자**: 없음(`elevation` 토큰 삭제, 현재 사용 0곳). 시트·모달은 `overlay` 로 띄운다.

## 6. 움직임

| 토큰 | 길이 | 용도 |
|---|---|---|
| `fast` | 150ms | 누름 반응, 칩 선택 |
| `base` | 250ms | 시트 열기/닫기, 토스트 |
| `slow` | 350ms | 덱 카드 넘김 |

- 감속 곡선 하나(`Easing.out(Easing.cubic)`). 튀는 효과(spring overshoot) 쓰지 않음.
- 시스템 '동작 줄이기' 켜짐이면 이동 없이 투명도만 바꾼다.

## 7. 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|---|---|
| **Button** | `primary`: primary 면 + onPrimary 글자, 화면당 1개. `secondary`: 면 없음 + `line` 테두리 + `text` 글자. `text`: 글자만, `text` 색 + 밑줄 없음. 높이 48 이상, 모서리 `sm`, 글자 `body` 600. 비활성 = 투명도 0.4. 로딩 = 글자 자리에 회색 스피너 |
| **Chip (필터)** | 기본: `surface` 면 + `text` 글자. 선택: `text` 면 + `bg` 글자(흑백 반전, 강조색 아끼기). 높이 36, 터치 영역 48 확보(hitSlop) |
| **Tag (배지)** | `surface` 면 + `textMuted` 글자, `caption`, 모서리 `pill`. 업무추진비·가성비·협찬 표시·근거 수준 모두 같은 모양 — 문구로만 구분. 문구는 "공공기관 업무추진비 기록 N회" 고정 |
| **ReelCard** | 배경 `bg` 전체, 테두리·그림자 없음. 위→아래: 별점(hero) → 가게 이름(title) → 태그 줄 → 이유(body, textMuted). 한 카드에 태그 최대 3개 |
| **ActionRail** | 아이콘 28(윤곽선, `text`), 라벨 `caption`. 선택 시 채운 아이콘 + `primary` + 라벨 변경("좋아요 완료") |
| **Sheet** | `bg` 면, 위쪽 모서리 `lg`, 손잡이 막대 36×4 `line`. 뒤 `overlay` |
| **Tab bar** | `bg` 면 + 위쪽 hairline. 선택 = `text` 채운 아이콘 + 라벨 600, 나머지 = `textFaint` 윤곽 아이콘 (screens.md 0절의 'primary 색' → `text` 로 변경 제안, §8 질문 2) |
| **점수 막대 (상세)** | 막대 = `text`, 리뷰 평균 = `primary`, 감점 = `danger`, 바탕 = `surface` |

## 8. 승인이 필요한 결정

1. **글꼴**: 시스템 기본 글꼴 유지(추가 용량 0) vs Pretendard 탑재(한글 일관성↑, 약 +1MB). 추천: Pretendard.
2. **선택 상태 색**: 칩·탭 선택을 흑백 반전(추천 — 강조색이 '최상' 별점에만 남아 의미가 또렷해짐) vs 기존처럼 primary.
3. **강조색 톤**: `#D1451F`(현재 주황을 조금 진하게, AA 통과) 유지 vs 다른 색. 브랜드 정체성이 걸린 결정.
4. **'좋음' 구간 색**: 초록 → `text`(검정)로 바꾸면 '평범'과의 차이가 진하기 차이뿐 — 라벨 텍스트가 있어 구분은 되지만, 체감 차이가 약하다는 반론 가능.

## 9. 적용 순서 (승인 후)

1. `tokens.ts` 를 새 이름으로 교체하되, 한 PR 안에서 기존 이름 → 새 이름 치환까지 끝낸다(별칭 안 남김).
2. 하드코딩 3곳 토큰화 → `npx tsc --noEmit`.
3. Button·Chip·Tag 를 규칙대로 수정 → 화면별 스크린샷(라이트/다크) 비교.
4. QA: 대비·터치 영역 점검(`docs/qa/report_design_v1.md`), 결함은 기록 후 수정.
5. `screens.md` 의 색 언급(0절 탭, 4-3 지도 등) 갱신.
