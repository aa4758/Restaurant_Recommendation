# QA 리포트 (4단계)

범위: `docs/01_planning_decision.md` 점수 모델·API 계약 ↔ `backend/app/`, `mobile/src/api/client.ts` 대조 + API 엣지케이스 탐색.
결과: **high 0건.** pytest 15개 통과, `npx tsc --noEmit` 통과.

## 계약 일치
| 항목 | 결과 |
|---|---|
| 6개 엔드포인트 경로·메서드·상태코드(201/202/404/422) | 일치 |
| item 필드 16종, `score_breakdown` 6종, 모바일 타입 | 일치 |
| prior: w_gov=0.25, GOV_CAP=30, w_ad=0.30, 임계 0.15/0.5, ad_conf | 일치 (+ floor: base의 50% 보장) |
| strict: 평균≈2.5, 4.5 이상 상위≈3% | 일치 (시드 평균 테스트 포함) |
| bayes k=20, n=20에서 50:50 | 일치 |
| 완화 순서 거리→분위기→가격→장르, 음주 불완화, 동점대 ±0.1 일 단위 로테이션 | 일치 |
| "공직자" 표현 미사용, 업무추진비 PII 컬럼 없음 | 일치 |

## 이슈
| # | 심각도 | 내용 | 조치 |
|---|---|---|---|
| 1 | medium | 리뷰 `text`/`tags`, 신고 `field`/`message` 길이 무제한 (200KB 본문 저장 확인) | ✅ 수정: text·message ≤1000, tags ≤10개×20자, field ≤50. 모바일 입력 `maxLength` 추가. 테스트 추가 |
| 2 | medium | 로그인 없이 리뷰 무제한 작성 → 별점 조작 가능 | MVP 범위상 보류(로그인 2차). 공개 전 IP 레이트리밋 또는 기기 ID 필요 |
| 3 | low | 반경 내·완화 후에도 0건이면 `relaxed:["distance"]`만 반환 | 의도된 동작. 모바일은 빈 상태 화면 표시 |
| 4 | low | 장르만 불일치해도 거리부터 완화(순서 고정) → 반경 밖 가게가 섞일 수 있음 | 결정문 순서 그대로. 변경 시 01 문서 먼저 |
| 5 | low | 요청마다 전체 점수 재계산 | 48곳 MVP에선 무시 가능. 수천 곳 이상이면 캐시 |
