## 이상 없음
식·상수(업력 20년 cap, 업무추진비 30회 cap, 위생 1/0.7/0.4, 지정업소, 제휴 결측 0.5, 처분 0.05·상한 0.15, 광고 식·하한), 날짜·NULL·음수 경계, N+1 없음(추천·상세 각 2쿼리, 재계산은 지역당 상수 쿼리), "공직자" 문구 없음, reasons 3줄, 모바일 타입 일치.
